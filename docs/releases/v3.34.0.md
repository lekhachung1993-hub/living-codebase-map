# LCM v3.34.0 — Living Evidence and Safe Scale

This release completes roadmap phases 31–34: auditable proof infrastructure, a reusable engine boundary, operational evidence lifecycle, and safe incremental graph construction.

## Highlights

- `scripts/proof_campaign.py` aggregates multi-repository baseline/candidate campaigns and rejects runs without repository, execution, and transcript provenance.
- `scripts/scale_benchmark.py` records commit-pinned cold and warm measurements without executing target repository code.
- `RepositoryEngine` separates reusable repository-state orchestration from CLI and MCP surfaces.
- Graph planning and context compilation now live in a dedicated core module.
- `.lcm/observations.json` stores hash-backed test, coverage, runtime, benchmark, and CI evidence.
- `observe` and `evidence-status` expose deterministic `FRESH`, `SUSPECT`, and `STALE` transitions.
- Graph cache reuse supports warm no-change updates and safe file-level partial rebuilds while symbol-resolution signatures remain unchanged.
- Symbol-resolution signature or resolution-environment changes conservatively trigger a full graph rebuild.

## Evidence boundary

The checked-in scale report measures engine behavior on clean public repositories. It does not claim improved agent task success. Such a claim still requires retained, independently executed baseline and LCM-assisted transcripts processed through the proof campaign gate.

## Compatibility

- Core CLI remains Python 3.8+ standard-library only.
- Index schema remains v4.
- Graph schema advances to v3 for operational observation nodes and relationships.
- Constraint schema remains v2; observation schema begins at v1.
- CALM remains an optional adapter and is not part of the internal evidence model.
